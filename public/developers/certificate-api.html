Certificate verification API

Check a printed certificate id from the foundation's main website. Each issued certificate has its own 12-digit id.

Base URL: https://seminar.vaidyagogate.org

No API key, login, or email code is required. The response does not include the holder's email or phone.

Request

GET /api/public/certificates/verify/{certificateId}

GET /api/public/certificates/verify?id={certificateId}

Spaces and dashes are ignored. The value must be exactly 12 digits.

curl -sS "https://seminar.vaidyagogate.org/api/public/certificates/verify/433495146392"

Valid certificate

HTTP 200.

{
  "ok": true,
  "valid": true,
  "status": "valid",
  "certificateId": "433495146392",
  "kind": "participant",
  "holderName": "Dr Asha Gogate",
  "prn": "PRN2600000001",
  "applicationNo": "SEM-2026-0015",
  "event": { "id": 9, "title": "Manas Rog 3", "date": "2026-02-04" },
  "issuedAt": "2026-02-05T10:00:00.000Z",
  "message": "This certificate is authentic and was issued by the Vaidya Gogate Memorial Foundation."
}

kind is participant or volunteer. Show the name and event only when valid is true.

Other results

HTTPstatusMeaning
200validIssued and active.
200not_foundNo certificate uses this id.
200not_issuedThe id exists, but the certificate is not active. The name is omitted.
400invalid_idNot 12 digits.
429rate_limitedMore than 60 lookups from one address in a minute.

Browser

const res = await fetch(
  "https://seminar.vaidyagogate.org/api/public/certificates/verify/" +
  encodeURIComponent(id.replace(/\D/g, ""))
);
const body = await res.json();

The certificate id is assigned when that certificate is issued. Creating an event does not create ids by itself. Use this id, not the application number or PRN, as the lookup key.
